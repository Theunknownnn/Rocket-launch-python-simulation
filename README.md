# Rocket-launch-python-simulation
A simple rocket launch simulation with a rough sketch of the drag coefficient.

## Features
- Gravity
- Fuel burn
- Aerodynamic drag (Rough)
- Atmospheric density layers (Non-gradual)
- Velocity & height plots

## Technologies
- Python
- NumPy
- Matplotlib

## Simplifications
- vertical only flight
- constant gravity
- simplified atmosphere layers

## Future improvements
- 2d flight
- Orbital mechanics
- Variable gravity
- Staging
